# Skill2UI v0.1.0

First public runnable release. The MIT project provides a Python runtime, browser workbench, standard Agent Skill and optional MCP Apps adapter for turning natural-language tasks and imported Skills into validated interfaces.

## Downloads

- [Python wheel](https://github.com/sharbvane/Skill2UI/releases/download/v0.1.0/skill2ui-0.1.0-py3-none-any.whl)
- [Source distribution](https://github.com/sharbvane/Skill2UI/releases/download/v0.1.0/skill2ui-0.1.0.tar.gz)
- [Source archive](https://github.com/sharbvane/Skill2UI/releases/download/v0.1.0/Skill2UI-0.1.0-source.zip)
- [SHA-256 checksums](https://github.com/sharbvane/Skill2UI/releases/download/v0.1.0/SHA256SUMS.txt)

Install the wheel with Python 3.11 or newer:

```sh
python -m pip install https://github.com/sharbvane/Skill2UI/releases/download/v0.1.0/skill2ui-0.1.0-py3-none-any.whl
skill2ui serve --port 7860
```

## Verification

- 53 Python tests and 19 frontend assertions passed.
- Browser acceptance groups A–E passed in Chromium, including approved execution of an unchanged third-party document Skill.
- The official MCP SDK client and a simulated MCP Apps host completed real stdio and browser checks.
- Wheel installation and startup were checked in an isolated virtual environment.

Actual paid model access, production Codex/Claude embedding, Linux/macOS execution and PDF visual rendering were not verified. Approved scripts retain the current user's disk and network permissions; Skill2UI does not provide an OS sandbox. See [acceptance](../acceptance.md) and [security](../security.md).
