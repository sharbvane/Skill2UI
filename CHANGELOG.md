# Changelog

## 0.1.0 — 2026-10-12

First runnable release: standard Agent Skill, CLI/API, loopback runtime, seven local task layouts, optional validated models, static local/ZIP/GitHub import, source/version linkage, registered typed actions and explicitly approved jobs. Includes state-preserving edits, save/restore, charts, files, logs, result/output previews.

Original MIT third-party document validation Skill and independent CSV example. Official MCP/MCP Apps SDK adapter for generation, arithmetic and inspection. Acceptance distinguishes browser execution, structural validation, simulated providers and actual/simulated host checks.

Future work: OS sandbox, broader interfaces, provider streaming, A2UI/AG-UI interoperability and production-host certification. No external publication performed.
